AI Dispatch

Start work for each carrier you add. Loads come from brokers or a licensed JSON API.

Three ways a load reaches the board

  1. A broker posts it on LoadsNexus. That path is already live.
  2. You paste a licensed load-board API here. The desk calls that https JSON URL with your key. It does not open websites or copy another board’s pages.
  3. When a load is covered, expired, or missing from the latest API reply, it leaves the public board.

The board stays empty until a broker posts or an API returns real loads. Start sends a good-morning text asking for the empty ZIP. A broker is not called until the driver replies YES on that exact load.

FMCSA email outreach

AI pulls active carriers (1–20 trucks) and brokers with an email on file from the public FMCSA registry. Carriers get up to four emails over about three weeks, from Shipping Wish and LoadsNexus. Brokers get up to three emails from LoadsNexus. Emails go out Monday–Friday, 9 a.m.–5 p.m. in each company’s own time zone.

It starts small and raises the daily limit only while bounces and unsubscribes stay low. It slows down when they rise and pauses itself if they cross the safe line. A reply, an unsubscribe, a bounce, or a signup stops the emails to that company. Cold contacts never get texts or AI calls.
