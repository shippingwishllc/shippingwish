📲 How to Install & Test on Your Device

METHOD A: INSTANT VIA EXPO GO (NO BUILD NEEDED)

1 Install Expo Go from Google Play Store or iOS App Store.

2 In terminal run: npm run mobile:carrier

3 Scan QR code with Expo Go (Android) or Camera (iOS). The app opens instantly!

METHOD B: STANDALONE ANDROID APK

1 Run npm run build:carrier:apk in terminal.

2 Expo Cloud automatically compiles the Android APK and outputs a download link.

3 Download to your phone, tap Install, and run natively without Expo Go!
