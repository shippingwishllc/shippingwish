📖 Official Social Media API Setup & Zero-Ban Guide

🛡️ Kyun Humare Accounts Block Nahi Honge?
Hum koi illegal browser bot ya scraping extension use nahi karte. Hum Meta aur LinkedIn ke Official Developer Portals se generate kiye gaye business tokens use karte hain jo 100% legal aur compliant hain.

1. Meta (Facebook Pages & Instagram Business) API Hasil Karne Ka Tareeqa:

  1. Go to developers.facebook.com par login karein.
  2. Create App dabayein → Type select karein: Business.
  3. App Dashboard me add karein: Facebook Pages API aur Instagram Graph API.
  4. Tools → Graph API Explorer par jayein. Apna Facebook Page select karein aur permissions tick karein: pages_manage_posts, pages_read_engagement, instagram_content_publish.
  5. Generate Access Token dabayein aur is token ko Long-Lived (Never Expire) me convert karein.
  6. Page ID aur Token copy karke hamare API Credentials box me paste kar dein!

2. LinkedIn Company Page API Hasil Karne Ka Tareeqa:

  1. Go to linkedin.com/developers → Create App.
  2. App ko apne official LinkedIn Company Page ke sath verify/connect karein.
  3. Products tab me add karein: Share on LinkedIn.
  4. Auth tab me permissions: w_organization_social.
  5. OAuth 2.0 Token aur Organization URN copy karke hamare dashboard me save karein.
